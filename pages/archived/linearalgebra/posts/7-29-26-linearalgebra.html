Vector Spaces and Subspaces

Reccomended listening: Joe Hisaishi Mother's Broom - Joe Hisaishi

Reading (the beginnings) of some number of linear algebra texts has revealed to me some of the evolution
of how the material has been taught.

Older texts usually begin by defining matricies and determinants - newer ones tend to first define vector spaces.

I do not know enough to understand why this change occured, but it is interesting.

Besides that, the particular text I am using uses the modern approach - vector space forward.

So, what is a vector space?

A set \(V\) is a vector space over a field \(F\) iff:

We are able to define operations +:\((VxV) \to V\) and *:\((FxV)\to V\) such that,
for any elements \(x,y,z\in V\) and \(a,b\in F\):

  1. \(x+y=y+x\)
  2. \((x+y)+z=x+(y+z)\)
  3. \(\exists 0 \in V,x+0=x\)
  4. \(\forall x\exists m \in V, x + m = 0\)
  5. \(\forall x, 1x = x\)
  6. \((ab)x = a(bx)\)
  7. \(a(x+y)=ax+ay\)
  8. \((a+b)x=ax+bx\)
There are some important examples of vector spaces in section 1.2 of the Friedberg (most notably tuples, matricies, set of functions
from a set \(S\) to field \(F\), and set of polynomials).

Further, a subspace is a subset of a vector space that is also a vector space with the same field and operations.
Conveniently, since a subspace is a subset of a vector space and the operations are given, most of the points in the
above list are automatically covered.
We just have to ensure the operations are well defined, and the elements required by items 3 and 4 remain in the subspace.

So:

A set \(W\) is a subspace of a vector space \(V\) over a field \(F\) iff:

For any elements \(x,y\in W\) and \(a\in F\):

  1. \(x+y\in W\)
  2. \(ax \in W\)
  3. \(\exists 0 \in W\)
  4. \(\forall x\exists m \in W, x + m = 0\)
Notice cleverly, as on page 17 of the Friedberg, point 4 is implied by point 2 as the additive inverse of a vector \(x\)
is (-1)*x which is in \(W\) by point 2.

We can now consider some prominent subfields:
  1. Symmetric matricies
  2. Diagonal matricies
  3. Set of all real valued continuous functions with domain of all reals
  4. Set of all polynomials with degree less than some natural number n
Notice also that the intersections of subspaces are also subspaces, as every subspace contains 0 and the closed-ness of + and *
on every subspace implies that, \(\forall x,y\in \text{intersection, } \exists x+y,ax \in \text{ every subspace} \implies\)
\(\exists x+y,ax \in \text{intersection}\)

Sources:

Linear Algebra 4th ed. - Friedberg, Insel, Spence [Pages 1-19]
